# ChairView branding

The dashboard's system name is **ChairView**. Its custom emblem combines a graduation cap, ascending analytics bars and a C-shaped viewing arc, in burgundy and navy. It is a project identity rather than an official university seal.

- Asset: [`public/chairview-logo.png`](../public/chairview-logo.png).
- Generation: built-in `image_gen` tool, with a transparent background; no CLI fallback.
- Uses: top header and browser favicon. The header academic-year badge follows the existing reporting filter.
- The existing dashboard remains one application page. The printed report carries the ChairView name without adding the full screen header.

## Exact generation prompt

Use case: logo-brand. Create ONE original logo emblem for ChairView, an academic analytics and decision-support dashboard for a university Program Chair. Emblem only, NO letters and NO words. Design a cohesive, simple geometric mark combining a graduation cap with three ascending analytics bars, subtly framed by an open C-shaped viewing arc. Professional university software brand, crisp flat vector-like silhouette, generous negative space, confident clean geometry, highly legible at 48px and as a favicon. Primary burgundy red #A21D35 with a restrained dark navy #10213A accent. Balanced square composition, emblem fills about 85% of canvas. Genuinely transparent background. No mockup, no 3D, no gradients, no shadow, no watermark, no seal, no official university symbols, no surrounding text, no extra variants.
